# Lumen — live wallpapers for Windows

Lumen puts animated, video and interactive web wallpapers on your Windows desktop, behind your icons, on every
monitor. It pauses itself when a game or fullscreen app is running, so it stays out of your way.

It comes with three wallpapers (**Cheveyo Interactive**, **Aurora** and **Constellation**), plays your own videos,
GIFs, images and web pages, and includes **Lumen Studio** for turning any video into an interactive silhouette
wallpaper.

## Install

1. Download **[Lumen-Setup.exe](https://github.com/CheveyoInteractive/Lumen-releases/releases/latest/download/Lumen-Setup.exe)**.
2. Run it. Windows may show *"Windows protected your PC"* because the installer isn't code-signed. Click
   **More info → Run anyway**.
3. Lumen opens. Pick a wallpaper and click **Set on all displays**.

Windows 10 (2004 or newer) or Windows 11, 64-bit. Nothing else to install.

## Updates

Lumen updates itself. It checks for new versions every few hours, downloads them in the background, and installs
them the next time it restarts (or straight away, quietly, while it's only running in the tray).
**Settings → Updates** shows the current state and has a **Check now** button.

## Uninstall

Windows **Settings → Apps → Installed apps → Lumen → Uninstall**. Your normal wallpaper comes back.
